# Codeflow FM — Brand Book v1

## 1. Brand Overview

**Brand name:** Codeflow FM

**Category:** Productivity music app / radio-style audio app for coding and deep work

**Core concept:**  
Codeflow FM is a curated radio experience for developers, makers, and knowledge workers. Users choose a genre station and immediately enter a focused listening environment without playlist hunting, algorithm fatigue, or decision overload.

**Primary product behavior:**  
Click a genre. Start a station. Get into flow.

**Key differentiator:**  
Unlike general-purpose music products, Codeflow FM is built around **instant focus through curated stations**, not infinite browsing.

## 2. Brand Essence

### Mission

### Value proposition
- Less choice paralysis
- Faster entry into deep work
- Consistent audio atmosphere
- A product that feels native to builder culture

## 3. Brand Pillars

### 1. Flow over friction
The product removes unnecessary decisions. The user should not need to search, build playlists, or overthink what to play.

### 2. Curation over clutter
Each genre station should feel intentional, editorial, and trustworthy.

### 3. Atmosphere over noise
The product exists to shape an environment, not demand attention.

### 4. Precision over hype
The brand should feel intelligent, restrained, and well-designed.

### 5. Consistency over novelty
Users return because the product is dependable. It becomes part of a work ritual.

## 15. Logo Direction

### Logo strategy
Use a clean wordmark with an optional compact symbol.

### Wordmark approach
- “Codeflow” should carry the main weight
- “FM” should feel technical and secondary
- Avoid playful or overly decorative treatment

### Symbol ideas
- Waveform integrated into a “C” or “CF”
- Frequency line / signal bar motif
- Tuner needle over a horizontal line
- Angle bracket + play symbol hybrid
- Circular radio mark with minimalist current line

### Logo behavior
Create a responsive system:
1. Full lockup: `Codeflow FM`
2. Compact lockup: `CFM` or `CF`
3. App icon: symbol only

### Logo attributes
The logo should look:
- crisp at small sizes
- clean in monochrome
- strong on dark backgrounds
- distinctive without being noisy

### Avoid
- Generic music notes
- Complex equalizer icons
- Cartoonish radio illustrations
- Overly retro typography

- Slate — `#8D99A8`
- Signal Blue — `#4DA3FF`
- Violet Glow — `#8B7CFF`
- Cyan Drift — `#59E1D9`

### Usage guidance
- Use dark neutrals for most of the interface
- Use accent colors sparingly
- Reserve glow treatments for active states, playback, and branding moments
- Avoid rainbow interfaces or high-saturation overload

### Gradients
Use gradients only as atmosphere layers, not as decoration everywhere.

Recommended gradient combinations:
- Signal Blue → Violet Glow
- Violet Glow → Cyan Drift
- Deep navy → soft violet haze

## 17. Typography

### Brand type direction
Typography should feel technical, contemporary, and comfortable during long sessions.

### System recommendation
Use a two-tier type system:
- **Primary sans-serif** for interface, headings, and brand
- **Monospace accent** for metadata, timer, station states, or subtle developer cues

### Desired traits
- high legibility
- restrained geometry
- slightly technical tone
- good rendering in dark interfaces

### Possible font directions
Sans:
- Inter
- Geist
- Söhne-style neo-grotesk
- SF Pro / equivalent modern system sans

Mono accent:
- JetBrains Mono
- IBM Plex Mono
- Geist Mono

### Type usage guidelines
- Headings: clean and compact
- Body: highly readable
- Metadata: mono or small caps style
- Avoid overly wide, soft, or playful fonts

- Keep the brand calm and precise
- Use the radio metaphor consistently
- Design for low friction

- Add too many playful visual effects
- Make the interface socially noisy

- Turn the brand into a generic streaming clone
